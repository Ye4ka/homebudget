# E2E ТЕСТ-СЦЕНАРИИ ДЛЯ HOMEBUDGET

## ОБЗОР
Документ содержит end-to-end тест-кейсы для проверки функциональности приложения HomeBudget.

## ЦЕЛИ ТЕСТИРОВАНИЯ
- Проверить основной функционал
- Обеспечить стабильность работы
- Выявить критические ошибки
- Подготовить приложение к релизу

## ТЕСТОВЫЕ ДАННЫЕ
**Пользователь:** testuser / TestPass123!
**Бюджет:** Личный бюджет
**Категории:** Зарплата (доход), Продукты (расход)

## ТЕСТ-КЕЙСЫ (1-5)

### TC-001: РЕГИСТРАЦИЯ НОВОГО ПОЛЬЗОВАТЕЛЯ
**Приоритет:** Высокий  
**Предусловие:** Пользователь не зарегистрирован

**Шаги:**
1. Открыть страницу регистрации (/register)
2. Заполнить поля:
   - Имя пользователя: newuser_test
   - Email: newuser@test.com
   - Пароль: SecurePass123!
   - Подтверждение пароля: SecurePass123!
3. Нажать "Зарегистрироваться"
4. Проверить перенаправление на главную страницу
5. Проверить отображение имени пользователя в шапке

**Ожидаемый результат:**
- Пользователь успешно зарегистрирован
- Происходит автоматический вход в систему
- Отображается главная страница приложения

---

### TC-002: ДОБАВЛЕНИЕ ДОХОДА
**Приоритет:** Высокий  
**Предусловие:** Пользователь авторизован, создан бюджет

**Шаги:**
1. Перейти на страницу транзакций (/transactions)
2. Нажать "Добавить доход"
3. Заполнить форму:
   - Сумма: 50000
   - Категория: Зарплата
   - Дата: текущая дата
   - Описание: Аванс за декабрь
   - Бюджет: Личный бюджет
4. Нажать "Сохранить"
5. Перейти на главную страницу (/dashboard)

**Ожидаемый результат:**
- Транзакция добавлена в список
- Баланс бюджета увеличивается на 50000
- В статистике отображается новый доход

---

### TC-003: ДОБАВЛЕНИЕ РАСХОДА
**Приоритет:** Высокий  
**Предусловие:** Пользователь авторизован, баланс > 0

**Шаги:**
1. Перейти на страницу транзакций (/transactions)
2. Нажать "Добавить расход"
3. Заполнить форму:
   - Сумма: 2500
   - Категория: Продукты
   - Дата: текущая дата
   - Описание: Покупки в супермаркете
   - Бюджет: Личный бюджет
4. Нажать "Сохранить"
5. Перейти на главную страницу

**Ожидаемый результат:**
- Транзакция добавлена в список
- Баланс бюджета уменьшается на 2500
- В статистике отображается новый расход

---

### TC-004: РЕДАКТИРОВАНИЕ ТРАНЗАКЦИИ
**Приоритет:** Средний  
**Предусловие:** Существует хотя бы одна транзакция

**Шаги:**
1. Перейти на страницу транзакций
2. Найти транзакцию "Аванс за декабрь"
3. Нажать "Редактировать" (иконка карандаша)
4. Изменить сумму с 50000 на 55000
5. Изменить описание на "Зарплата за декабрь"
6. Нажать "Сохранить"
7. Вернуться на главную страницу

**Ожидаемый результат:**
- Транзакция обновлена
- Баланс бюджета изменен на +5000
- В списке транзакций отображаются новые данные

---

### TC-005: УДАЛЕНИЕ ТРАНЗАКЦИИ
**Приоритет:** Средний  
**Предусловие:** Существует хотя бы одна транзакция

**Шаги:**
1. Перейти на страницу транзакций
2. Найти транзакцию "Покупки в супермаркете"
3. Нажать "Удалить" (иконка корзины)
4. Подтвердить удаление в диалоговом окне
5. Вернуться на главную страницу

**Ожидаемый результат:**
- Транзакция удалена из списка
- Баланс бюджета увеличивается на 2500
- В статистике расходы уменьшаются

## ТЕСТ-КЕЙСЫ (6-9)

### TC-006: ФИЛЬТРАЦИЯ ПО ТИПУ (ДОХОД/РАСХОД)
**Приоритет:** Низкий  
**Предусловие:** Есть несколько транзакций разных типов

**Шаги:**
1. Перейти на страницу транзакций
2. Нажать на фильтр "Тип"
3. Выбрать "Доходы"
4. Проверить отображение только доходных транзакций
5. Выбрать "Расходы"
6. Проверить отображение только расходных транзакций
7. Выбрать "Все"
8. Проверить отображение всех транзакций

**Ожидаемый результат:**
- Фильтр корректно работает
- Отображаются только транзакции выбранного типа
- Счетчик транзакций обновляется

---

### TC-007: ФИЛЬТРАЦИЯ ПО КАТЕГОРИИ
**Приоритет:** Низкий  
**Предусловие:** Есть транзакции в разных категориях

**Шаги:**
1. Перейти на страницу транзакций
2. Нажать на фильтр "Категория"
3. Выбрать категорию "Зарплата"
4. Проверить отображение только транзакций этой категории
5. Выбрать другую категорию
6. Проверить отображение транзакций новой категории

**Ожидаемый результат:**
- Отображаются только транзакции выбранной категории
- Фильтр сбрасывается при выборе "Все категории"

---

### TC-008: ФИЛЬТРАЦИЯ ПО ДАТЕ
**Приоритет:** Средний  
**Предусловие:** Есть транзакции за разные даты

**Шаги:**
1. Перейти на страницу транзакций
2. Нажать на фильтр "Дата"
3. Выбрать "За сегодня"
4. Проверить отображение только сегодняшних транзакций
5. Выбрать "За последние 7 дней"
6. Проверить отображение транзакций за неделю
7. Выбрать произвольный диапазон дат
8. Проверить отображение транзакций в этом диапазоне

**Ожидаемый результат:**
- Корректная фильтрация по датам
- Отображаются только транзакции в выбранном диапазоне
- Интерфейс календаря работает правильно

---

### TC-009: LOGOUT/LOGIN
**Приоритет:** Высокий  
**Предусловие:** Пользователь авторизован

**Шаги:**
1. Нажать на аватар пользователя в шапке
2. Выбрать "Выйти"
3. Проверить перенаправление на страницу логина
4. Ввести логин/пароль тестового пользователя
5. Нажать "Войти"
6. Проверить перенаправление на главную страницу

**Ожидаемый результат:**
- Успешный выход из системы
- Данные сессии очищаются
- Успешный вход с теми же учетными данными
- Состояние приложения сохраняется

## КРИТЕРИИ ПРОХОЖДЕНИЯ ТЕСТОВ

### Обязательные:
- Все тесты 1-9 должны проходить успешно
- Не должно быть критических ошибок (500 Internal Server Error)
- Все основные функции должны работать

### Желательные:
- Прохождение дополнительных тестов 10-14
- Время загрузки страниц < 3 секунд
- Корректная работа на всех поддерживаемых браузерах

### Опциональные:
- Производительность при большом количестве данных
- Работа оффлайн (если реализовано PWA)
- Push-уведомления

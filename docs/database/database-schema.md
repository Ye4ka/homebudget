# 🗃️ СХЕМА БАЗЫ ДАННЫХ

## ТАБЛИЦЫ:
1. `users` - пользователи
2. `budgets` - бюджеты  
3. `budget_members` - участники
4. `categories` - категории
5. `transactions` - транзакции
6. `goals` - цели
7. `notifications` - уведомления

## СВЯЗИ:
- Пользователь → Бюджеты (владелец)
- Бюджет → Транзакции (содержит)
- Категория → Транзакции (классифицирует)

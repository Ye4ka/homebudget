🏗️ ПРЕДСТАВЛЕНИЯ (VIEWS)
monthly_summary
Назначение: Представление для быстрого доступа к сводной месячной статистике.

Структура:

CREATE VIEW monthly_summary AS
SELECT 
    budget_id,
    budget_name,
    year,
    month,
    total_income,
    total_expense,
    balance,
    total_transactions
FROM ...
Использование:

-- Получить месячную статистику для бюджета
SELECT * FROM monthly_summary WHERE budget_id = 1 ORDER BY year, month;

-- Суммарная статистика за год
SELECT 
    SUM(total_income) as year_income,
    SUM(total_expense) as year_expense 
FROM monthly_summary 
WHERE budget_id = 1 AND year = 2024;
category_totals
Назначение: Представление для анализа данных по категориям.

Структура:

CREATE VIEW category_totals AS
SELECT 
    budget_id,
    category_name,
    category_type,
    total_amount,
    transaction_count
FROM ...
Использование:

-- Топ категорий по расходам
SELECT * FROM category_totals 
WHERE budget_id = 1 AND category_type = 'expense'
ORDER BY total_amount DESC;

-- Статистика по всем категориям
SELECT 
    category_type,
    COUNT(*) as category_count,
    SUM(total_amount) as total_by_type
FROM category_totals 
WHERE budget_id = 1
GROUP BY category_type;
